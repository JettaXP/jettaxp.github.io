Telegram CLI

Terminal-based Telegram client for Linux

Features

  • Blazing Fast (C++ & TDLib)
  • Multi-theme support (Dark, Nord, Gruvbox)
  • Keyboard-driven workflow
  • exteraGram badges & Stars support

Install Now

curl -sL https://raw.githubusercontent.com/JettaXP/Telegram-CLI/main/install.sh | sudo bash

> run 'tgcli' to start
