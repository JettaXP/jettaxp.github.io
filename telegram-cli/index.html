Telegram CLI


Terminal-based Telegram client for Linux

SYS_STATUS: ONLINE
VER: 1.0.0

Features

  • Blazing Fast (C++ & TDLib)
  • Multi-theme support (Dark, Nord, Gruvbox)
  • Keyboard-driven workflow
  • exteraGram badges & Stars support

Keyboard Shortcuts

  • F2 Toggle Info Panel
  • PgUp/Dn Scroll Chat History
  • Esc Cancel Reply / Edit
  • Ctrl+C Quit App

Commands

Type inside the input bar (prefix with :)

:stars => Toggle Stars balance
:gifts => Toggle Gifts & NFT panel
:theme => Switch UI theme (dark, nord, gruvbox)
:logout => Log out of your account

Install Now

curl -sL https://raw.githubusercontent.com/JettaXP/Telegram-CLI/main/install.sh | sudo bash

> run 'tgcli' to start
